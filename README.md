# Khet2Cart – Demand-Aware Direct Farm-to-Market Network

A Python-based terminal prototype developed for Smart India Hackathon.

## Core Idea

Predict → Plan → Procure → Optimize → Deliver → Rebalance

The system connects farmer supply with consumer demand while considering:

- Multi-farmer sourcing
- Exact quantity allocation
- Location and logistics
- Route optimization
- Supply gap detection
- Surplus detection
- Dynamic re-optimization
- Payment workflow
- Delivery tracking

## Technology

- Python
- SQLite
- Google Maps API
- OpenWeather API
- Razorpay Test Mode
- Firebase Notifications

## Running the Prototype

Install Python dependencies and run:

python sih_prototype.py
